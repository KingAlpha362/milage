# Fuel Consumption Converter

A Python exercise converting miles per gallon to litres per 100 kilometres.

## ✨ Highlights

- Reads an MPG value.
- Applies `235.2 / mpg` and formats the result to two decimal places.

## 🚀 Getting started

Install Python 3, open a terminal in this repository, then run:

```sh
python "milee.py"
```

Follow the prompts in the terminal.

## 🗂️ Repository guide

- [milee](milee)
- [milee.py](milee.py)

## 📝 Project notes

Enter a positive, non-zero number. Invalid numeric input and zero are not handled.
